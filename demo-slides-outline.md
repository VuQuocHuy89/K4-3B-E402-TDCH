# Demo slides outline

1. User & Job — user cụ thể, job, pain và evidence.
2. Vì sao chọn bài toán — bảng impact ít nhất 3 ứng viên.
3. Giải pháp & demo — một case chuẩn và một case khó.
4. Kết quả đo — % trên golden set so với quality bar.
5. User thật nói gì — quote và thay đổi sau validation; nếu chưa validation, nêu kết quả test.
6. Nếu có thêm một tuần — 2–3 việc ưu tiên và bài học lớn nhất.
